📱 홈 화면에 앱처럼 설치

브라우저로 접속한 뒤 홈 화면에 추가하면, 일반 앱처럼 아이콘을 눌러 전체 화면으로 바로 열 수 있습니다.

🍎 아이폰 · 아이패드 (Safari)

  1. Safari로 이 사이트를 엽니다. (크롬이 아닌 사파리 권장)
  2. 아래쪽 공유 버튼(□ 위로 화살표 ↑)을 누릅니다.
  3. 목록을 내려 「홈 화면에 추가」 를 누릅니다.
  4. 오른쪽 위 「추가」 → 바탕화면에 아이콘이 생깁니다.

🤖 안드로이드폰 (Chrome)

  1. Chrome으로 이 사이트를 엽니다.
  2. 오른쪽 위 메뉴(⋮) 를 누릅니다.
  3. 「앱 설치」 또는 「홈 화면에 추가」 를 누릅니다.
  4. 「설치 / 추가」 → 바탕화면에 아이콘이 생깁니다.
설치 후에는 아이콘으로 전체 화면으로 사용하세요. 처음 한 번만 로그인하면 다음부터 자동 로그인됩니다.

1. 시작하기

회원가입

  • 이름 · 핸드폰 · 이메일 · 비밀번호(확인) · 직군 · 자기소개를 입력합니다.
  • 웹에서 가입할 때는 사용 핸드폰 종류(아이폰/안드로이드)와 앱 설치용 연결 이메일도 입력합니다. (TestFlight·내부테스터 초대에 사용)
  • 가입 직후에는 승인 대기 상태입니다. 관리자가 승인하면 방 목록이 보입니다.

로그인

  • 이메일 또는 핸드폰번호 + 비밀번호로 로그인합니다.
  • 비밀번호를 잊었다면 로그인 화면의 재설정을 이용합니다. (전체관리자 계정은 보안상 재설정 불가)
폰 앱과 웹은 같은 계정·같은 대화를 실시간으로 공유합니다.

2. 방 목록 (홈)

로그인 후 첫 화면입니다. 맨 위부터 순서대로:

전체공지 병실현황 학술활동
  • 전체공지 — 과 전체 공지. 관리자 글이 카드 형태로 표시됩니다.
  • 병실현황 — 남·여 잔여 병상 메모를 확인·편집합니다. (교실·의국·간호사·관리자 편집 가능)
  • 당직표 — 병실현황 화면 상단의 당직표 탭. 교원 당직과 평일 전공의 낮당직·당직·외래, 휴일 당직을 날짜별로 보고 입력합니다. (교실·의국·비서·관리자 편집 가능)
  • 학술활동 — 학술 일정·자료 방. 열면 주간 캘린더가 기본입니다.
  • BugReport — 앱 오류·개선 제안. 새 글 알림은 전체관리자만 받습니다.
  • ＋ 모임방 만들기 — 카톡처럼 이름과 참여 회원을 골라 모임방을 만듭니다.

아래 목록에는 모임방과 1:1 대화가 표시됩니다. 안 읽은 메시지가 있으면 숫자 배지가 붙습니다.

방 순서 고정

⚙️ 설정 → 방 순서에서 최대 5개를 고정·드래그 정렬할 수 있습니다. 전체공지는 항상 맨 위이며 고정 대상에서 제외됩니다.

3. 채팅

  • 하단 입력창에 글을 쓰고 ➤ 를 눌러 전송합니다.
  • ＋ 버튼: 사진 또는 파일을 선택 → 미리보기 확인 후 ➤ 로 전송 (카톡과 동일).
  • 말풍선 길게 누르기: 복사 · 부분 복사 · 답장 · 이모지 반응(👍 ❤️ 😂 😮 😢 👏).
  • 답장하면 상단에 원문 미리보기가 뜨고, 보낸 메시지에는 인용이 함께 표시됩니다.
  • 입력창은 여러 줄 자동 확장됩니다. (웹: 줄바꿈은 Enter, 전송은 Ctrl/⌘+Enter 또는 ➤)
  • 아주 긴 메시지는 화면에서 줄여 보여주고, 전체보기를 누르면 전문이 새 화면으로 열립니다.
  • 내가 쓴 글 옆 🗑: 삭제 (본인·관리자).
  • 방을 열면 읽음 처리되어 안 읽음 배지가 사라집니다. 메시지마다 안 읽은 사람 수도 표시됩니다.
과 전체공지는 일반 말풍선이 아니라 가운데 정렬된 공지 카드로 표시됩니다. 길게 눌러 복사할 수 있습니다.

4. 자료실 · 캘린더

모임방·학술활동 등 기본 방에는 상단에 세 탭이 있습니다.

📁 자료실

  • 직접 업로드한 파일과 캘린더 일정 첨부를 한곳에 모읍니다.
  • 날짜순 / 키워드별 정렬.
  • 파일명과 업로드 시 적은 설명이 함께 표시됩니다.

📅 캘린더

  • 보기: 금일 · 주간 · 월간.
  • 일정 필드: 제목 · 시간 · 장소 · 링크 · 참석범위 · 설명 · 키워드 · 첨부파일+설명.
  • 수정·삭제: 작성자 본인 + 관리자 (일정 삭제는 일부 직군 추가 허용).

5. 모임방

  • 만든 사람(생성자)과 관리자는 ⚙️ 설정에서 구성원 초대·제거, 방 삭제가 가능합니다.
  • 본인이 만들지 않은 모임방은 헤더 나가기로 목록에서만 제거됩니다. (대화는 보존)
  • 헤더 이름변경: 생성자 또는 관리자 (기본 방은 전체관리자만).
  • 방 표식: 만들 때·이름 변경 시 색상·사진 아바타를 지정할 수 있습니다.

6. 1:1 대화

  1. 방 목록 ⚙️ 설정 → 회원 검색
  2. 상대를 찾아 메시지 버튼을 누릅니다.
  3. 방 목록에서 해당 1:1 행을 왼쪽으로 스와이프 → 확인 후 삭제 (내 목록에서만, 상대·이력 보존).

1:1 방에는 캘린더·자료실 탭이 없고 채팅만 사용합니다.

7. 설정 (⚙️)

내 정보

  • 자기소개 · 아바타(사진/색) · 다크/라이트 테마 · 비밀번호 변경.
  • 핸드폰 종류(아이폰/안드로이드)와 앱 설치용 이메일은 변경할 수 있습니다.
  • 이름 · 이메일 · 전화번호는 읽기 전용입니다. (전화번호 변경이 필요하면 관리자에게 문의)

방 순서

자주 쓰는 방 최대 5개 고정·드래그 정렬.

회원 검색

동료 이름·직군·이메일·전화로 검색, 1:1 메시지 시작.

회원 탈퇴

본인 계정 비활성화. 작성한 글·자료는 보존되며 로그인만 차단됩니다. 전체관리자는 탈퇴 불가.

8. 문의 · BugReport

  • 앱 오류·개선 아이디어: 홈의 BugReport 버튼 → 버그·제안 글 작성.
  • 계정·승인·방 관련: 전체관리자에게 연락하세요.
첨부 파일·채팅 사진은 약 4주 후 자동 정리될 수 있습니다. 중요 자료는 별도 보관을 권장합니다.

🔔 새 메시지 알림(푸시) 켜기

앱(브라우저)을 닫아둬도 새 메시지가 오면 알려줍니다. 받을 기기마다 한 번만 ‘알림 허용’ 하면 됩니다.

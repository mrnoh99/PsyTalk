# 공지 — 아주 정신 iOS(아이폰) 앱 설치 안내 (TestFlight 내부 테스트)

> 내부 테스트 그룹 배포 → 각자 **이메일로 받은 TestFlight 초대**로 설치합니다.
> (공개 링크 없음 / 안드로이드는 이미 배포되어 별도 안내 불필요)

---

## 전체공지용 (복붙)

```
📢 아주 정신 아이폰(iOS) 앱 설치 안내

아이폰 사용자분들께 ‘아주 정신’ 앱 테스트 초대를 보냈습니다.
등록된 이메일로 받은 ‘TestFlight 초대’로 설치해 주세요.
(안드로이드는 이미 배포되어 그대로 사용하시면 됩니다)

1) 아이폰 App Store에서 ‘TestFlight’ 앱을 설치합니다.
2) 본인 이메일로 온 ‘TestFlight 초대’ 메일을 엽니다.
   (보낸사람: TestFlight / Apple, 제목에 ‘아주 정신’ 또는 ‘TestFlight’)
   → 메일의 ‘View in TestFlight(테스트플라이트에서 보기)’ 를 누릅니다.
   ※ 메일이 없으면 스팸함 확인 / 알려주시면 다시 보내드립니다.
3) TestFlight에서 ‘아주 정신’ 을 설치(Install)합니다.
4) 앱 실행 → 회원가입(이름·핸드폰번호·이메일·비밀번호·직군)
5) 전체관리자 승인 후 로그인하면 이용할 수 있습니다. (승인 전엔 ‘승인 대기’ 화면)
6) 첫 로그인 때 ‘알림 허용’ 을 눌러주세요. (새 메시지 푸시 알림)

■ 도움말
· 사용법: https://mrnoh99.github.io/PsyTalk/guide.html
· 알림 설정: https://mrnoh99.github.io/PsyTalk/notify-guide.html
· 오류·건의: 앱 안 ‘BugReport’ 방
```

## 카톡용 (짧게)

```
[아주 정신 아이폰 앱 설치]
1. App Store에서 ‘TestFlight’ 설치
2. 이메일로 온 ‘TestFlight 초대’ 열기 → ‘View in TestFlight’ → ‘아주 정신’ 설치
3. 가입 → 관리자 승인 후 로그인 → 알림 허용
※ 초대 메일 없으면 스팸함 확인/문의. (안드로이드는 이미 배포됨)
사용법: https://mrnoh99.github.io/PsyTalk/guide.html
```

## 운영 메모 (관리자용)
- 내부 테스트는 **App Store Connect ‘사용자 및 액세스’에 등록된 사람**에게만 초대가 갑니다.
  초대가 안 간 사람은 거기서 사용자로 추가 후 내부 그룹에 넣어야 합니다.
- 초대 메일은 **그 사람의 이메일(Apple ID 권장)** 로 발송됩니다. 다른 이메일이면 수락 시 Apple ID 로그인 필요.
- 새 빌드 올리면 내부 그룹은 **베타 심사 없이 바로** 테스터에게 업데이트 알림이 갑니다.
- 더 많은 인원(최대 1만, 공개 링크)이 필요하면 ‘외부 테스트’로 전환하면 됩니다.

---

📖 **상세 사용법 보기 👉** https://mrnoh99.github.io/PsyTalk/guide.html

📢 **아주 정신(PsyTalk) 사용 안내**

안녕하세요. 정신건강의학과 의국 그룹 메신저 **아주 정신**입니다.
공지·일정·자료·당직표·채팅을 한 곳에서 사용할 수 있습니다.

**시작하기**
• 가입 후 관리자 승인이 되면 로그인됩니다.
• 로그인: 이메일 또는 핸드폰번호 + 비밀번호

**주요 기능**
• 📋 과 전체공지 — 과 단위 공지 확인
• 📚 주간 학술활동 — 학술 일정·자료
• 🛏 잔여 병실 현황 / 당직표 확인
• 💬 모임방 — 카톡처럼 직접 방을 만들어 채팅·사진/파일 공유
• 🗓 캘린더(금일·주간·월간) · 자료실(업로드·정렬)
• 🙋 1:1 대화, 답장·이모지 리액션
• ⚙️ 설정에서 내 정보(소개·사진·핸드폰 종류) 변경

문의·오류 제보는 방 목록의 **BugReport** 방에 남겨주세요. 감사합니다.

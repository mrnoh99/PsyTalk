## 앱별 상세 (관리자/기록용)

### 공통 (웹 · iOS · Android)
- 새 메시지 푸시 알림(OneSignal). external_id=회원 id.
- 주간 학술활동 ↔ Google Calendar 양방향 동기화(last-write-wins).
- 사진 첨부 자동 인라인(확장자/MIME 로 image 판정).
- 모임방 만들기 회원 선택: 검색 + 가나다순/직군별 정렬.
- (전체관리자) 회원 이름·직군 수정.

### iOS
- 채팅 키보드 내리기: 빈 곳 탭 / 메시지 드래그 / 방 나갈 때 자동 해제.
- 모임방 만들기 키보드: 화면 아무 곳 탭하면 내림(@FocusState).
- 앱 표시 이름 ‘아주 정신’, Bundle ID `com.mrnoh99.psytalk`.

### Android (v1.2 / versionCode 2)
- 상단 콘텐츠가 상태바와 겹치던 문제 수정(edge-to-edge 인셋).
- 시스템 BACK: 열린 화면을 먼저 닫고 최상위에서만 종료.
- 채팅·모임방 빈 곳 탭으로 키보드 내림(clearFocus + keyboardController.hide).

### 웹
- 푸시 알림 연동, ‘구글 캘린더 동기화’ 버튼을 방 헤더로 이동.

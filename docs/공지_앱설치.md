# 공지 — 아주 정신 앱 설치 안내

> 전체공지방/메일/카톡에 붙여 쓰는 설치 공지. `<TestFlight 공개 링크>` 만 실제 링크로 바꾸세요.

---

## 전체공지용 (복붙)

```
📢 아주 정신 앱 설치 안내

정신건강의학과 의국 메신저 ‘아주 정신’ 입니다. 기기에 맞게 설치해 주세요.

■ 아이폰 · 아이패드 (TestFlight)
1) App Store에서 ‘TestFlight’ 앱 설치
2) 아래 링크 열기 → ‘아주 정신’ 설치
   👉 <TestFlight 공개 링크>

■ 안드로이드 · PC · 맥 (웹 — 설치 없이 바로 사용)
1) 크롬/사파리로 접속: https://mrnoh99.github.io/PsyTalk/
2) (앱처럼 쓰려면)
   · 안드로이드 크롬: 메뉴(⋮) → ‘홈 화면에 추가 / 앱 설치’
   · 아이폰 사파리: 공유 → ‘홈 화면에 추가’ (※ 아이폰은 이렇게 해야 알림 받음)

■ 공통
1) 회원가입: 이름·핸드폰번호·이메일·비밀번호·직군 입력
2) 전체관리자 승인 후 로그인하면 이용 가능 (승인 전엔 ‘승인 대기’ 화면)
3) 첫 로그인 시 ‘알림 허용’ → 새 메시지 푸시 알림

■ 도움말
· 사용법: https://mrnoh99.github.io/PsyTalk/guide.html
· 알림 설정(기기별): https://mrnoh99.github.io/PsyTalk/notify-guide.html
· 오류·건의: 앱 안 ‘BugReport’ 방
```

## 보내기 전 채울 것
- `<TestFlight 공개 링크>` : App Store Connect → TestFlight → 외부 테스트 그룹 → **공개 링크(Public Link)**.
  아직 없으면 “TestFlight 초대 메일을 수락” 으로 안내해도 됩니다.
- 아이폰은 **iOS 16.4 이상 + 홈 화면 추가(웹의 경우)** 라야 푸시 알림이 옵니다.

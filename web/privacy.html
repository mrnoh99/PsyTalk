아주 정신 개인정보처리방침

시행일: 2026년 6월 · 아주대학교병원 정신건강의학과

「아주 정신」(이하 ‘서비스’)은 정신건강의학과 구성원 전용 그룹 메신저입니다. 본 방침은 서비스 이용 과정에서 처리되는 개인정보에 대해 안내합니다.

1. 수집 항목

  • 회원가입: 이름, 이메일, 핸드폰번호, 직군, 자기소개, (선택) 앱 설치용 이메일·기기 구분
  • 서비스 이용: 채팅 메시지, 첨부파일·사진, 일정·자료실 업로드, 프로필 사진·색상
  • 기술 정보: OS·기기 정보(BugReport 제보 시), 푸시 알림용 기기 토큰(OneSignal)

2. 이용 목적

  • 회원 식별·가입 승인, 부서 내 업무 소통
  • 공지·일정·자료 공유, 1:1 메시지
  • 서비스 오류 신고(BugReport) 처리
  • 새 메시지 푸시 알림(선택·권한 허용 시)

3. 보관 기간

  • 회원 정보: 탈퇴(비활성) 시까지 — 탈퇴 후 로그인 차단, 작성 콘텐츠는 부서 기록 보존 정책에 따름
  • 채팅 첨부·자료실 직접 업로드: 서버 정책에 따라 약 28일 경과 후 자동 삭제될 수 있음

4. 제3자 제공·위탁

서비스 운영을 위해 다음 외부 서비스를 사용합니다.

  • Supabase — 인증·DB·파일 저장 (호스팅 지역: 프로젝트 설정에 따름)
  • OneSignal — 푸시 알림 발송(앱에서 권한 허용한 경우)
  • GitHub Pages — 웹 클라이언트·본 방침 페이지 호스팅

5. 이용자 권리

설정에서 자기소개·프로필을 변경할 수 있으며, 회원 탈퇴를 요청할 수 있습니다. 가입 승인·계정 문의는 과 관리자에게 연락하세요.

6. 안전 조치

  • 관리자 승인 후 이용, 역할 기반 접근 제어
  • 전송 구간 HTTPS 암호화
  • Android 앱: 클라우드 백업 비활성화(로그인 세션 보호)

7. 문의

개인정보 관련 문의: 아주대학교병원 정신건강의학과 서비스 관리자
앱 내 BugReport 또는 과 관리자에게 문의해 주세요.

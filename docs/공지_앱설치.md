> 아이폰 사용자용 TestFlight 설치 공지. `<TestFlight 공개 링크>` 만 실제 링크로 바꾸세요.

## 전체공지용 (복붙)

```
📢 아주 정신 아이폰(iOS) 앱 설치 안내

아이폰 사용자분들은 아래 순서로 ‘아주 정신’ 앱을 설치해 주세요.
(안드로이드는 이미 배포되어 그대로 사용하시면 됩니다)

1) App Store에서 ‘TestFlight’ 앱을 먼저 설치합니다.
2) 아래 링크를 아이폰에서 열어 ‘아주 정신’을 설치합니다.
   👉 <TestFlight 공개 링크>
3) 앱 실행 → 회원가입(이름·핸드폰번호·이메일·비밀번호·직군)
4) 전체관리자 승인 후 로그인하면 이용할 수 있습니다. (승인 전엔 ‘승인 대기’ 화면)
5) 첫 로그인 때 ‘알림 허용’ 을 눌러주세요. (새 메시지 푸시 알림)

■ 도움말
· 사용법: https://mrnoh99.github.io/PsyTalk/guide.html
· 알림 설정: https://mrnoh99.github.io/PsyTalk/notify-guide.html
· 오류·건의: 앱 안 ‘BugReport’ 방
```

## 보내기 전 채울 것
- `<TestFlight 공개 링크>` : App Store Connect → TestFlight → 외부 테스트 그룹 → **공개 링크(Public Link)**.
  아직 없으면 “TestFlight 초대 메일을 수락” 으로 안내해도 됩니다.
- 아이폰은 **iOS 16.4 이상** 이라야 푸시 알림이 옵니다(설치·사용은 그 이하도 가능).

# 공지 — 새 버전 변경사항 (회원 전달용)

> 카톡/전체공지에 붙여 쓰는 회원용 변경 안내. 앱별로 구분. 비기술 용어로 작성.

---

## 전체공지용 (복붙)

```
📢 아주 정신 앱 업데이트 안내

새 버전이 나왔습니다. 더 편하게 쓰실 수 있도록 아래가 좋아졌어요.

[공통 — 웹 · 아이폰 · 안드로이드]
🔔 새 메시지 푸시 알림 — 앱(브라우저)을 닫아둬도 새 메시지를 알려줍니다.
   · 첫 로그인 때 ‘알림 허용’을 눌러주세요. (아이폰은 홈 화면에 추가 후 허용)
📅 주간 학술활동이 구글 캘린더와 자동으로 양방향 동기화됩니다.
🖼 사진을 첨부하면 항상 사진으로 바로 보입니다. (파일로 안 뜸)
🔎 모임방 만들 때 회원을 ‘검색’하고 ‘가나다순/직군별’로 정렬해 고를 수 있어요.
👥 (전체관리자) 회원 이름·직군을 바로 수정할 수 있습니다.

[아이폰]
⌨️ 채팅 키보드를 빈 곳 탭/메시지 드래그로 내릴 수 있고, 방을 나가면 자동으로 내려갑니다.

[안드로이드]
🔝 상단 화면이 시계·배터리 표시와 겹치던 문제를 고쳤습니다.
↩️ 뒤로가기 버튼이 앱을 바로 끄지 않고, 열린 화면을 단계적으로 닫습니다.
⌨️ 채팅에서 빈 곳을 탭하면 키보드가 내려갑니다.

[웹]
🔄 푸시 알림과 ‘구글 캘린더 동기화’ 버튼이 방 상단으로 정리됐습니다.

업데이트 방법
· 아이폰: TestFlight에서 ‘아주 정신’ 업데이트
· 안드로이드: (배포 경로)에서 업데이트
· 웹: 새로고침(Cmd/Ctrl+Shift+R)

문의·오류는 앱 안 ‘BugReport’로 남겨주세요.
```

## 카톡용 (짧게)

```
[아주 정신 업데이트]
🔔 새 메시지 푸시 알림(앱 닫아도) — 로그인 후 ‘알림 허용’
📅 주간 학술활동 ↔ 구글 캘린더 자동 동기화
🖼 사진 첨부는 항상 사진으로 표시
🔎 모임방 만들 때 회원 검색·가나다순/직군별 정렬
(아이폰) 키보드 내리기 개선 / (안드로이드) 상단 겹침·뒤로가기 종료 수정
→ 아이폰: TestFlight 업데이트 / 웹: 새로고침
```

## 앱별 상세 (관리자/기록용)

### 공통 (웹 · iOS · Android)
- 새 메시지 푸시 알림(OneSignal). external_id=회원 id.
- 주간 학술활동 ↔ Google Calendar 양방향 동기화(last-write-wins).
- 사진 첨부 자동 인라인(확장자/MIME 로 image 판정).
- 모임방 만들기 회원 선택: 검색 + 가나다순/직군별 정렬.
- (전체관리자) 회원 이름·직군 수정.

### iOS
- 채팅 키보드 내리기: 빈 곳 탭 / 메시지 드래그 / 방 나갈 때 자동 해제.
- 앱 표시 이름 ‘아주 정신’(CFBundleDisplayName/Name), Bundle ID `com.mrnoh99.psytalk`.

### Android
- 상단 콘텐츠가 상태바와 겹치던 문제 수정(edge-to-edge 인셋 적용).
- 시스템 BACK: 열린 화면(방/설정/관리자/방만들기/병실/일정 상세)을 먼저 닫고 최상위에서만 종료.
- 채팅 빈 곳 탭으로 키보드 내림.

### 웹
- 푸시 알림 연동, ‘구글 캘린더 동기화’ 버튼을 방 헤더(이름변경↔설정)로 이동.

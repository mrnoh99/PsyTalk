# 모임톡 UI 프로토타입

**기준 스펙:** [`docs/모임톡_요구사항.md`](../docs/모임톡_요구사항.md)

인터랙티브 HTML 목업(방 목록, 시점 전환, 채팅·자료실·캘린더, 관리자 콘솔, 멀티 방 게시)은 위 요구사항을 바탕으로 만든 **프로토타입 UI**입니다.

## 파일

- `index.html` — HTML 목업 전체. 팀원이 브라우저에서 바로 열어볼 수 있습니다.

## Android 앱과의 관계

| 프로토타입 | 앱 |
|------------|-----|
| HTML + JS 목 데이터 | Supabase + Kotlin Compose |
| 10명 시점 전환 (데모) | 로그인 사용자 1명 |
| 기본 방 12개 (주간 학술활동 포함) | 동일 기준 12방 (`seed_rooms.sql`) |

앱은 프로토타입 **레이아웃·색·탭 구조**를 맞추는 중이며, DB·관리자·멀티게시 등은 단계적으로 연동합니다.

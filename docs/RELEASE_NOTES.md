# 출시 노트 (Release Notes) — 아주 정신

> 앱스토어 / 플레이스토어 / TestFlight 출시 시 사용하는 사용자용 변경 사항입니다.
> 최신 버전이 맨 위. 스토어에는 각 버전의 **[스토어용]** 블록을 그대로 붙여넣으면 됩니다.

---

## v1.2.0 — 2026-06 · 사용성 개선

**개선/수정**
- 🖼 사진 첨부는 항상 사진으로 인라인 표시(파일로 뜨던 문제 수정).
- 🔎 모임방 만들기 회원 선택에 검색 + 가나다순/직군별 정렬 추가.
- 🍎 iOS: 채팅 키보드 내리기(빈 곳 탭/드래그/방 나갈 때) 개선, 앱 이름 ‘아주 정신’ 표기.
- 🤖 Android: 상단이 상태바와 겹치던 문제 수정, 뒤로가기(BACK)가 앱을 바로 끄던 문제 수정, 빈 곳 탭으로 키보드 내림.
- 🌐 웹: 동기화 버튼을 방 헤더로 정리.

**[스토어용]**
```
사진 첨부가 항상 사진으로 표시됩니다.
모임방 만들 때 회원 검색·정렬(가나다순/직군별)이 추가됐습니다.
아이폰 키보드 내리기, 안드로이드 상단 겹침·뒤로가기 종료 문제를 고쳤습니다.
그 외 안정성 개선.
```

## v1.1.0 — 2026-06 · 푸시 알림 · 구글 캘린더 동기화

**새로운 기능**
- 🔔 **새 메시지 푸시 알림** — 웹·아이폰·안드로이드에서 앱을 닫아둬도 새 메시지를 알림으로 받습니다.
  (아이폰은 ‘홈 화면에 추가’ 후 알림을 허용해 주세요)
- 📅 **주간 학술활동 ↔ 구글 캘린더 양방향 자동 동기화** — 앱과 구글 캘린더의 일정이 서로 자동 반영됩니다.
- 👥 **관리자 기능 개선** — 전체관리자가 회원의 이름·직군을 바로 수정할 수 있습니다.
- 🛠 그 외 안정성·사용성 개선.

**[스토어용]** (플레이스토어 출시 노트 500자 이내)
```
새 메시지 알림이 도착합니다 🔔
- 웹·아이폰·안드로이드에서 앱을 닫아둬도 새 메시지를 푸시 알림으로 받습니다.
  (아이폰은 ‘홈 화면에 추가’ 후 알림 허용)
주간 학술활동이 구글 캘린더와 양방향 자동 동기화됩니다 📅
관리자가 회원 이름·직군을 수정할 수 있습니다 👥
그 외 안정성 및 사용성 개선.
```

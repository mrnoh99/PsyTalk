# 테스터 안내문 (아주 정신 — iOS TestFlight)

> 카톡/메일로 보낼 수 있게 정리한 초대 안내문입니다. 상황에 맞게 골라 쓰세요.
> 공개 링크 방식이면 `<여기에 TestFlight 공개 링크>` 를 실제 링크로 바꾸면 됩니다.

---

## A. 카톡용 (짧게)

```
[아주 정신 앱 베타테스트 안내] 📱

의국 메신저 ‘아주 정신’ 아이폰 앱을 테스트로 설치해 주세요.

1) App Store에서 ‘TestFlight’ 앱 설치
2) 아래 링크 열기 → ‘아주 정신’ 설치
   👉 <여기에 TestFlight 공개 링크>
3) 앱 실행 → 회원가입(이름·핸드폰·이메일·직군)
4) 관리자 승인 후 로그인하면 이용 가능
5) 처음 로그인 시 ‘알림 허용’ 눌러주세요 (새 메시지 알림)

* 아이폰 전용입니다. 문제가 있으면 앱 안의 ‘BugReport’로 알려주세요.
```

---

## B. 메일/공지용 (자세히)

제목: **[아주 정신] 아이폰 앱 베타테스트 설치 안내**

```
안녕하세요. 정신건강의학과 의국 메신저 ‘아주 정신’ 아이폰 앱을
TestFlight로 베타 배포합니다. 아래 순서로 설치 부탁드립니다.

■ 설치 방법 (아이폰/아이패드)
1. App Store에서 ‘TestFlight’ 앱을 먼저 설치합니다.
2. 아래 초대 링크를 아이폰에서 엽니다.
   👉 <여기에 TestFlight 공개 링크>
   (또는 메일로 받은 TestFlight 초대의 ‘View in TestFlight’)
3. TestFlight에서 ‘아주 정신’을 설치(Install)합니다.

■ 가입 및 로그인
4. 앱을 실행하고 회원가입합니다. (이름·핸드폰번호·이메일·비밀번호·직군)
5. 가입 후 전체관리자 승인이 되면 로그인하여 이용할 수 있습니다.
   (승인 전에는 ‘승인 대기’ 화면이 보입니다)
6. 첫 로그인 때 알림 권한을 ‘허용’해 주세요. (새 메시지 푸시 알림)

■ 참고
- 아이폰/아이패드 전용입니다. (안드로이드·PC는 웹으로 이용:
  https://mrnoh99.github.io/PsyTalk/ )
- 알림이 안 오면: 설정 → 알림 → 아주 정신 → 허용 확인.
- 사용 중 오류·건의는 앱 안의 ‘BugReport’ 방으로 남겨주세요.

감사합니다.
```

## 보내기 전에 채울 것
- `<여기에 TestFlight 공개 링크>` : App Store Connect → TestFlight → 외부 테스트 그룹 →
  **공개 링크(Public Link)** 발급 후 붙여넣기.
  - 내부 테스터(이메일 초대) 방식이면 링크 대신 “메일로 온 TestFlight 초대를 수락” 안내.
- iOS 16.4 미만 기기는 푸시 알림 제한이 있을 수 있음(설치·사용은 가능).

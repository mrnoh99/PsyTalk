알림 받기 설정

앱 열기

새 메시지 알림 받기

알림을 켜두면 앱(브라우저)을 닫아둬도 새 메시지가 오면 알려줍니다. 본인 기기에서 한 번만 설정하면 됩니다.

내 기기 선택 ✅ 공통 — 먼저 이렇게 🍎 아이폰 · 아이패드 🤖 안드로이드폰 💻 PC 크롬 · 엣지 💻 맥 사파리 🔧 ‘차단’ 눌렀을 때 다시 켜기 🔔 잘 되는지 확인

✅ 공통 — 먼저 이렇게

  1. 웹앱( aumcpsy 주소 / 홈 화면 아이콘 )을 열고 로그인합니다.
  2. 로그인 직후 「알림을 표시하시겠습니까?」 가 뜨면 「허용」 을 누릅니다.
처음 한 번만 허용하면 됩니다. 창을 닫아도 알림은 옵니다. 받을 기기마다 한 번씩 허용하세요.
프롬프트가 안 뜨거나 실수로 닫았다면 — 아래에서 내 기기에 맞는 방법으로 켜세요.

🍎 아이폰 · 아이패드

아이폰은 ‘홈 화면에 추가(설치)’ 를 해야만 알림이 됩니다. (iOS 16.4 이상, Safari 사용)

1) 홈 화면에 추가

  1. Safari(크롬 ✗)로 사이트를 엽니다.
  2. 아래 공유 버튼(□ 위로 화살표 ↑) → 「홈 화면에 추가」 → 「추가」.

2) 알림 켜기

  1. 바탕화면에 생긴 아주 정신 아이콘으로 앱을 엽니다. (Safari 탭 말고 아이콘!)
  2. 로그인 → 「허용」.

안 떴거나 차단했다면

  1. 아이폰 설정 앱 열기 → 알림.
  2. 목록에서 아주 정신 찾기 → 「알림 허용」 켜기.
사파리 탭에서 그냥 보면 알림이 안 옵니다. 반드시 홈 화면 아이콘으로 설치해서 여세요.

🤖 안드로이드폰 (Chrome)

  1. Chrome으로 사이트를 열고 로그인 → 「허용」.
  2. (권장) 메뉴(⋮) → 「홈 화면에 추가 / 앱 설치」 로 설치해두면 앱처럼 편합니다.

차단했다면

  1. 주소창 왼쪽 자물쇠🔒(또는 ⓘ) → 권한 / 사이트 설정.
  2. 알림 → 허용 으로 변경 → 페이지 새로고침.

💻 PC 크롬 · 엣지 (윈도우/맥)

  1. 사이트를 열고 로그인 → 화면 위쪽 「알림 허용」 팝업에서 허용.

차단했거나 팝업이 없으면

  1. 주소창 맨 왼쪽 아이콘(자물쇠🔒/슬라이더) 클릭.
  2. 알림 을 허용 으로 변경 → 새로고침(Ctrl/Cmd+Shift+R).
크롬 주소창에 chrome://settings/content/notifications 입력 → ‘차단’ 목록에서 이 사이트를 ‘허용’으로 옮겨도 됩니다.

💻 맥 사파리 (Safari)

  1. 사이트를 열고 로그인 → 「허용」.

차단했다면

  1. 상단 메뉴 Safari → 설정(Settings) → 웹사이트 탭.
  2. 왼쪽 알림 선택 → 이 사이트를 허용.
  3. 추가로 맥 시스템 설정 → 알림 → Safari 가 켜져 있어야 합니다.

🔧 ‘차단’을 눌렀을 때 — 다시 켜기 요약

  • 아이폰: 설정 앱 → 알림 → 아주 정신 → 허용
  • 안드로이드: 주소창 🔒 → 알림 → 허용
  • PC 크롬/엣지: 주소창 🔒 → 알림 → 허용 → 새로고침
  • 맥 사파리: Safari 설정 → 웹사이트 → 알림 → 허용 (+ 시스템 설정 알림)
한 번 ‘차단’하면 팝업이 다시 안 뜹니다. 위처럼 수동으로 허용으로 바꿔야 합니다.

🔔 잘 되는지 확인

  • 알림을 허용한 뒤, 다른 사람이 내가 있는 방에 메시지를 보내면 알림이 옵니다.
  • 내가 보낸 메시지는 나에게 알림이 오지 않습니다. (정상)
  • 앱(브라우저)을 닫아둬도 알림이 옵니다.
  • 받을 기기/브라우저마다 각각 한 번씩 허용해야 합니다.
그래도 안 오면 전체관리자에게 알려주세요. (기기 종류·브라우저·‘알림 허용’ 상태를 함께 알려주시면 빠릅니다.)

# 전체공지용 안내문 — 홈 화면에 웹앱으로 설치

> 과 전체공지(전체 알림)에 올리는 안내문입니다.
> 앱 주소: https://mrnoh99.github.io/PsyTalk/
> superadmin 으로 로그인 → **과 전체공지** 방에 아래 본문을 복사해 게시.

---

📱 **아주 정신 — 폰 바탕화면에 앱처럼 설치하기**

브라우저로 접속한 뒤 홈 화면에 추가하면, 일반 앱처럼 아이콘을 눌러 바로 열 수 있습니다.
주소: **https://mrnoh99.github.io/PsyTalk/**

**🍎 아이폰 / 아이패드 (Safari)**
1. **Safari**(사파리)로 위 주소를 엽니다. ※ 크롬 아닌 사파리 권장
2. 아래쪽 **공유 버튼**(□ 위로 화살표 ↑)을 누릅니다.
3. 목록을 내려 **「홈 화면에 추가」** 를 누릅니다.
4. 오른쪽 위 **「추가」** 를 누르면 바탕화면에 아이콘이 생깁니다.

**🤖 안드로이드폰 (Chrome)**
1. **Chrome**(크롬)으로 위 주소를 엽니다.
2. 오른쪽 위 **메뉴(⋮)** 를 누릅니다.
3. **「앱 설치」** 또는 **「홈 화면에 추가」** 를 누릅니다.
4. **「설치 / 추가」** 를 누르면 바탕화면에 아이콘이 생깁니다.

이후에는 바탕화면 아이콘을 눌러 전체 화면으로 사용하면 됩니다.
처음 한 번만 로그인하면 다음부터는 자동 로그인됩니다.
